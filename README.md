# C# Learning & Practice

Репозиторий, в котором я системно изучаю C# и закрепляю материал на небольших практических задачах.

## Источники

- курсы и практические задания на Stepik;
- книга А. Н. Васильева по C#;
- самостоятельные задания и небольшие учебные проекты.

DeepSeek использую как вспомогательный инструмент: для объяснения сложных тем, разбора ошибок и проверки решений. Задачи стараюсь сначала решать самостоятельно, а затем анализирую возможные улучшения.

## Изученные темы

- [условные конструкции, циклы и обработка исключений](03-Control-Flow);
- [одномерные и многомерные массивы](04-Arrays);
- [методы, перегрузка, рекурсия, `ref` и `out`](05-Methods);
- [коллекции `List` и `Dictionary`](06-Collections);
- [самостоятельные практические задания](Independent-Tasks).
