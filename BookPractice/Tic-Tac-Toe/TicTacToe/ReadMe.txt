- Тема дипломной работы "Разработка консольной игры крестики-нолики".

Описание игры и её механник:

1. В игре участвуют два игрока: один играет за крестики (X), другой — за нолики (O);
2. По традиции, первым ходит игрок за крестики;
3. Игровое поле — это таблица 3×3;
4. Игроки ходят по очереди, делая по одному ходу — ставят свой символ в любую свободную клетку;
​​5. Цель игры — выстроить три одинаковых символа (крестика или нолика) в ряд, колонку или по диагонали.

Механника игры:

1. Для 9 ходов (повторить 9 раз):
    1.1. Вывести, чей сейчас ход: X или O
    1.2. Показать текущее состояние игрового поля
    1.3. Попросить ход игрока
    1.4. Проверить ввод:
        — число ли это от 1 до 9 и свободна ли выбранная клетка
            — если нет — попросить ввести снова
    1.5. Сделать ход (записать X или O в выбранную клетку)
    1.6. Проверить победу:
        — если есть победитель:
            — Показать поле
            — Вывести результат игры
            — Завершить программу
2. Показать текущее состояние игрового поля
3. Вывести информацию о ничьей

В случае, если в шаге 1.6 будет найдено условие для завершения игры, то шаги 2 и 3 выполняться не должны

Для удобства алгоритм будет в последствии разбит на отдельные функции.


Ход разработки и построение архитектуры кода:

1. Для 9 ходов (повторить 9 раз):
    1.1. Вывести, чей сейчас ход: X или O // 🔸 Main
    1.2. Показать текущее состояние игрового поля // 🔸 PrintMap
    1.3. Попросить ход игрока // 🔸 GetPlayerCellNumber
    1.4. Проверить ввод: 
        — число ли это от 1 до 9 и свободна ли выбранная клетка // 🔸 GetPlayerCellNumber + IsMoveCorrect 
            — если нет — попросить ввести снова
    1.5. Сделать ход (записать X или O в выбранную клетку) // 🔸 MakeMove
    1.6. Проверить победу:
        — если есть победитель: // 🔸 HasWinner
            — Показать поле // 🔸 PrintMap
            — Вывести результат игры // 🔸 Main
            — Завершить программу // 🔸 Main
2. Показать текущее состояние игрового поля // 🔸 PrintMap
3. Вывести информацию о ничьей // 🔸 Main

Игровое поле будет представлено в виде двумерного пронумерованного массива следующим образом:

string[,] map = new string[3, 3] 
{
    {"1", "2", "3"}, 
    {"4", "5", "6"}, 
    {"7", "8", "9"} 
};

Далее идет переход к написанию самой программы и функций. 


Функция PrintMap:

Используется для красивого вывода игрового поля в консоль.

1. Принимает двумерный массив (string[,]);
2. Выводит его в виде сетки 3×3;
3. Отображает символы с отступами (через пробел);
4. Крестики (X) окрашивает в красный цвет, нолики (O) — в голубой;
5. Остальные символы выводит стандартным цветом по умолчанию.


Функция IsMoveCorrect:

Используется для проверки текущего состояния выбранной ячейки.

1. Необходимо определить, занята ли соответствующая клетка на игровом поле.
2. Функция IsMoveCorrect принимает два параметра:
    string[,] map — текущее состояние игрового поля;
    string cellNumber — номер выбранной игроком ячейки.
3. Функция возвращает true, если ячейка свободна (т.е. содержит номер), и false, если в ячейке уже стоит X или O.


Функция GetPlayerCellNumber:

Используется для получения от пользователя корректного номера ячейки, который запрашивает у пользователя
ввод до тех пор, пока тот не введет корректное значение.

1. Принимает один параметр: string[,] map — текущее состояние игрового поля;
2. ​​​​Запрашивает у пользователя ввод;
3. Проверяет:
        является ли ввод числом;
        входит ли число в диапазон от 1 до 9;
        свободна ли ячейка с этим номером (используй для этого уже готовую функцию IsMoveCorrect);
4. Выводит соответствующие сообщения об ошибках:
        если не число от 1 до 9 → Неверный ввод. Пожалуйста, введите цифру от 1 до 9.
        если занятая ячейка → Неверный ввод. Пожалуйста, введите цифру пустой ячейки.
5. И возвращает строку — корректный номер ячейки.


Функция MakeMove:

Используется для выполнения хода игрком, а далее обновляет игровое поле, поставив в выбранную ячейку
символ "X" или "O"

1. Принимает три параметра:
        string[,] map — текущее состояние игрового поля
        string cellNumber — номер выбранной игроком ячейки (уже проверенный и гарантированно корректный);
        bool isZeroNow — логическое значение: если true, то сейчас ход ноликов, иначе — крестиков;
2. Находит на поле ячейку с номером cellNumber и заменяет её на:
        O, если isZeroNow == true;
        X, если isZeroNow == false;
3. Возвращает обновлённое игровое поле.


Функция HasWinner:

Используется для проверки наличия победителя на игровом поле

1. Принимает один параметр:
        string[,] map — текущее состояние игрового поля;
2. Проверяет все возможные варианты победы — строки, столбцы и обе диагонали — на наличие трёх одинаковых символов подряд (X или O);
3. Возвращает true, если победитель найден (т.е. есть три одинаковых символа в линии), иначе — false.
